# Simulasi Algoritma Tic Tac Toe

Proyek ini dibuat untuk keperluan makalah praktikum Analisis Strategi Algoritma (ASA).

## Algoritma yang diuji:
- Minimax
- Greedy
- BFS (Breadth-First Search)
- DFS (Depth-First Search)
- Brute Force

Pastikan Anda sudah menginstall Python 3.
